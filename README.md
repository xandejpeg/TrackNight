# TrackNight

Plataforma de análise de desempenho em pista (kart rental, track day e outras modalidades). No lançamento, o traçado aceito para análise é o **KGV — Circuito 101**.

## Deploy / VPS

* Produção hospedada no VPS **KVM 2 da Hostinger**.
* App em `/var/www/tracknight`, chave SSH `~/.ssh/tracknight_deploy`.
* Domínio definitivo: a registrar (ver `docs/ROADMAP.md`, fase 3).
